# 作品提出フォーム回答案

都知事杯オープンデータ・ハッカソン2026の[作品提出フォーム](https://form.jotform.com/261870604352051)へ入力する内容の下書き。フォームは2026年7月12日に確認し、2026年7月31日に項目構成・文字数制限・収録日程を再確認した。提出期限は **2026年8月23日（日）17:00（日本時間）**。期限後は提出・修正できないため、個人情報、公開名、URL、収録日時、権利関係を確定してから送信する。

`[要入力]` と `[要選択]` はリポジトリから確定できない項目。フォームへの送信はまだ行っていない。

## 最初に確定する項目

- チーム名とフリガナ。チーム名はWeb公開され、提出後に変更できない。
- 公開するメンバー名。ニックネームでもよいが、実名を使う場合は本人の同意が必要。
- 連絡担当者の本名、フリガナ、メールアドレス。Webには公開されない。
- 本番デモURL、操作動画URL、一般公開の可否。
- 収録方法と、空き枠から選ぶ収録日時。
- プレゼン資料と1600×900pxの画面キャプチャ。
- 生成画像、区章、オープンデータ等のライセンス確認。詳細は「権利関係の確認事項」を参照。

## 2. 提出作品の概要

### 2-1. 取り組んだ課題の種類（必須）

**入力案:** `自由課題（独自に設定した課題）`

2026年7月31日時点でも[公式テーマページ](https://odhackathon.metro.tokyo.lg.jp/issues/)にはアンケート結果が掲載されておらず（「7月中に公開予定」の表示のまま）、本作品も独自課題として設計・実装している。公開後に本作品と合致するテーマがあれば選び直しを検討するため、送信直前にもう一度同ページを確認する。

### 2-2. 作品名（必須・公開・提出後変更不可）

**入力案:** `うちの区ちゃん`

### 2-3. サービスの詳細（必須・公開用要約・310字以内）

**入力案（193字）:**

> 東京23区を、昼夜間人口比率・年齢構成・公園面積・世帯構成・財政力指数からなる5軸性格ベクトルで表し、擬人化した「区ちゃん」として巡れるWeb図鑑です。10問に答えると回答ベクトルに最も近い区を提示し、レーダー、にてる度、相性TOP3、区別の詳細指標・地図・政策出典まで確認できます。結果はXで共有可能。23区すべての結果・詳細ページを静的生成し、3D非対応時は2D表示へ切り替えます。

### 2-4. 着目した課題・背景（必須・310字以内）

**入力案（約200字）:**

> 多くの都民にとって、自分の暮らす区の取り組みやデータは関心の外にあります。例えば世田谷区の区民意識調査（2024年・n=2,404）では、区の取り組みや身近な情報を「特に入手していない」人が全体で25.2%、10代・20代では半数を超えます。東京都や各区のオープンデータが充実しても、そもそも関心のない人が「自分や暮らす地域」との接点としてデータに触れる入口がないことに着目しました。

数値は2026年7月31日に一次データで確認済み。出典は[世田谷区民意識調査2024](https://www.city.setagaya.lg.jp/02002/18440.html)の問9クロス集計（男性10・20歳代54.2%／女性10・20歳代59.2%。報告書・クロス集計Excel・ローデータが公開されている）。世田谷区1区の調査であるため「例えば世田谷区の調査では」の表現を崩さない。投票率（2023年統一分44.98%等）は代理指標で論理が飛躍するため主根拠から外した（経緯は[2分プレゼン構成案.md](2分プレゼン構成案.md) スライド②とチェックリストの表）。順位表示が優劣・スティグマにつながるという論点は、課題ではなく解決方法（2-5「優劣ではなく個性として可視化」）の設計思想として述べる。

### 2-5. 課題・背景の解決方法（必須・310字以内）

**入力案（約220字）:**

> 性格診断が流行するように、誰でも「自分がどうなのか」には強い関心があります。この“診断されたい”好奇心を入口に区への関心をつくる、関心の矢印を逆転させる体験を設計しました。複数の公式データを23区共通の5軸へ正規化し、優劣ではなく個性として擬人化。10問診断で回答ベクトルに最も近い「あなたに一番似ている区」と出会わせ、そこから実数値・出典・区の政策へ進める導線にします。3D図鑑、2Dフォールバック、共有カードで、楽しさ・アクセシビリティ・継続的な話題化を両立します。

「MBTI」は商標のため文面では使わず、「性格診断」の一般表現とする。文字数はフォーム上で再確認する（310字以内）。

## 3. 技術詳細

### 3-1. 技術選定の理由（必須・310字以内）

**入力案（298字）:**

> Next.js App Router／React／TypeScriptで23区分の結果・詳細ページを静的生成し、Cloudflare Pagesで低コスト・高可用に配信します。Python＋openpyxlでCSV/XLSXを23区単位に集計し、Vitestで件数・値域・対応関係を検証。Three.js／React Three Fiberは図鑑の没入感に使用し、WebGL非対応・reduced motion・Canvas失敗時は2Dへフォールバックします。実行時API・DB・認証を持たず、診断回答はsessionStorageだけに保存することで、デモの安定性とプライバシーを優先しました。

### 3-2. 生成AI等の活用方法（任意・310字以内）

**入力案（219字）:**

> ChatGPTを23区キャラクター画像とOGP画像の生成に使用しました。昼夜間人口比率、年齢構成、公園面積、世帯構成、財政力指数の実数から、衣装・小物・色・背景へ変換する共通ルールと統一スタイルを定め、区ごとの根拠→性格→プロンプトを記録。OGPは各区のキャラクター原本を参照画像として生成しました。生成結果は人が確認し、否定的な地域表現や文字・ロゴ混入を避けました。画像は事前生成して静的配信し、実行時に生成AIへデータを送信しません。

開発補助に使用した生成AIも申告対象と判断する場合は、実際に使用したツール名と用途を追記する。未使用のツール名は記載しない。相性解説・性格文などのテキストも生成AIで作成しており（UIに「AIによる相性解説」バッジを表示）、テキスト生成分も申告する場合はここへ追記する。

### 権利関係の確認事項

現行リポジトリだけでは、1つ目の同意を最終確定するための証跡が一部不足している。送信前に次を完了する。

- AI生成画像の権利関係は確認済みで、この項目に残作業はない。キャラクター原本・OGP原本・区アイコン・`assets/title.png`・`assets/book-cover.png` のすべてがChatGPT Businessによる生成で、[OpenAIサービス契約](https://openai.com/policies/business-terms/)4.1により出力の権利は契約組織に帰属する。契約主体は組織だが本作品での個人利用の承認を得ている。入力はテキストプロンプトか自作の生成物のみで第三者素材は使っていない。整理は [来歴台帳](../system-design/08-asset-provenance.md) の3章冒頭にある。`title.png` と `book-cover.png` はプロンプト未記録のため再現できない点だけ台帳に残している。来歴が未整理かつ現行ルートで未使用だった `assets/magic-circle.png` は削除済み。
- 区アイコンは23区分の生成と `npm run build:icons` による変換が完了しており、この項目に残作業はない。原本 `assets/icons/{slug}.png` と配信用 `public/icons/{slug}.webp` がそれぞれ23件そろっている。来歴台帳3.3の生成日欄も記入済み。
- 区章は使用しない。著作権はPublic domainだったが、新宿区・練馬区が紋章の使用承認要綱を、荒川区が届出要綱を持ち、千代田区は区サイトで二次利用を否定しているため、23区一律に適法と確認できないと判断して `public/emblems/` を削除した。経緯は来歴台帳2章に記録済みで、この項目に残作業はない。
- 10件のオープンデータと行政区域データについて、利用規約・ライセンス、加工の有無、取得日を確認する。アプリ内とプレゼン資料には出典と「加工して作成」の表示を残す。確認済みの状況は次のとおり。
  - 都のデータ5件（昼夜間人口比率、住民基本台帳年齢別人口、都市公園面積、外国人人口、警視庁認知件数）は東京都オープンデータカタログにリソースURL単位で登録されておりCC BY 4.0。事務局への利用照会は不要と判断した。
  - 待機児童数は当初、東京都福祉局「保育サービスの状況」（報道発表添付）を使っていたが、同資料はオープンデータカタログ未登録で、都サイトの著作権表示も二次利用を許諾していない「公表」データだった。事務局照会を不要にするため、同一数値を持つこども家庭庁「保育所等関連状況取りまとめ」（公共データ利用規約PDL1.0）へ差し替え済み。23区の値が完全一致することは確認済みで、都の元ファイルは `data/raw/` から削除した。
  - 国のデータ（地価公示、国勢調査、総務省の財政指標・課税状況）は各サイトの利用規約に基づき出典明記で二次利用可。行政区域TopoJSONの再配布元 `smartnews-smri/japan-topography` は、READMEでスマートニュースのクレジット不要・国土交通省のクレジット必要と明示している。
- 区の政策・花木鳥データは、23区すべてのサイトポリシーを確認済み（2026-08-13）。千代田区のみサイト全体がCC BYで、残る22区は私的使用・引用を除き二次利用を禁じている。基本構想の見出しを逐語で載せていた政策タイトル98件は、当方が書いた区固有のラベルへ全面的に置き換え済みで、`summary` も従来どおり自作の要約である。区詳細ページと診断結果ページに「各区の基本構想をもとに編集」バッジを表示する。詳細は [来歴台帳](../system-design/08-asset-provenance.md) の5章。
- 区の花・木・鳥は名称のみの掲載で、この項目に残作業はない。事務局へ照会し、2026-08-13に問題ない旨の回答を得た（名称は複数の独立した情報源から確認できる公知の事実情報であり、名称そのものは創作的表現ではなく、区サイトの文章表現を転載してもいないため、名称のみの表示であれば問題ないとの見解。ただし個別の法的判断を確約するものではない旨の付記あり）。回答の全文は [来歴台帳](../system-design/08-asset-provenance.md) の5.3に記録している。
- プレゼン資料、操作動画、画面キャプチャに第三者の写真、地図、BGM、フォント、商標等を追加する場合は、別途利用条件と帰属表示を確認する。音声を使う作品でないため、操作動画は無音とする。
